# Day 2 – Linux CLI & System Inspection

## Focus
Understanding how to inspect and navigate a Linux system using CLI commands,
without automation or abstraction.

## Commands Practised
pwd, ls, ls -a, ls -l, cd  
cp, mv, rm, rm -r  
free, df, top  
ping, ifconfig, ip a, netstat  

## Key Learnings
- Filesystem navigation builds system awareness
- System inspection commands are real-time and situational
- Not all command output should be logged
- DevOps requires interpretation, not blind data collection

## Notes
Day 2 focused on observation and reasoning, not persistence.
