# 🚀 InfraPilot-SandBox

## 📌 Project Overview......
**InfraPilot-SandBox** is a beginner-friendly DevOps learning project that demonstrates how a **frontend interface** can interact with a **Linux system** by executing shell commands and displaying their output.

The project is designed to help learners understand how operating systems are inspected and controlled programmatically — the same idea behind many real-world internal DevOps dashboards and tools.

---

## 🎯 What This Project Does (In Simple Terms)

- Provides a **frontend UI with buttons and inputs**
- Each button triggers a **Linux command** in the background
- Commands run on the **underlying Linux shell**
- The output is captured and shown back on the UI
- The project evolves incrementally, day by day

This project focuses on **visibility and control of system resources**, not automation at scale.

---

## 🧩 System Design (Frontend → Shell → OS)

### 📐 High-Level Architecture
User  
↓  
Frontend UI (Buttons / Inputs)  
↓  
Backend Script Layer (Shell / Python)  
↓  
Linux Operating System  
↓  
Frontend UI (Displays Output)
## 🧠 Learning Objectives

This project helps build understanding of:
- How frontends communicate with system-level logic
- How Linux commands expose OS state
- How DevOps tools surface system information
- How Git is used to track iterative development
- Why strong OS fundamentals matter before automation

---

## 🚧 Scope & Limitations

- This project is **not** a production monitoring tool
- It is **not** a full automation platform
- Security hardening is intentionally minimal
- The focus is **learning, not scale**
